## Introduction

URL Phishing is a type of cyberattack in which attackers create fraudulent websites to trick users into revealing sensitive information such as usernames, passwords, and banking details. 
With the increasing sophistication of phishing attacks, traditional detection techniques may not always be sufficient.

Machine Learning provides an approach to identifying suspicious patterns in website characteristics and classifying websites as **legitimate** or **phishing**.


## Objectives

1. Explore and understand the phishing websites dataset.
2. Perform data preprocessing and exploratory data analysis.
3. Analyse the importance of different website features.
4. Train multiple machine learning classification features.
5. Compare model performance using evaluation metrics.
6. Implement explainable AI to understand model predictions.


## Dataset Credit

Source: UCI Machine Learning Repository
Dataset: Phishing Websites
Authors: R. Mohammad, F. Thabtah, L. Mccluskey. 2012
Link: [https://archive.ics.uci.edu/dataset/327/phishing+websites](https://archive.ics.uci.edu/dataset/327/phishing+websites)

- Number of input features: 30
- Classification task: Binary classification
